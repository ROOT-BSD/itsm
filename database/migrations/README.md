# Міграції БД

* `legacy/001…040_*.sql` — «стиснена» історія до версії 0.3.0. **Не змінюються й не видаляються**: потрібні для оновлення зі старих версій.
* `041_*.sql` і далі (прямо в цьому каталозі) — нові міграції; кожна виконується один раз.
* Облік — таблиця `schema_migrations`; виконує `php bin/migrate.php` (його викликає `update.sh`).
  Режими: `--status`, `--dry-run`, `--baseline`.

## Як додати міграцію

1. Створіть `database/migrations/NNN_короткий_опис.sql`, де NNN — наступний за найбільшим номером (3 цифри).
2. Пишіть її **ідемпотентною**, якщо це можливо (`CREATE TABLE IF NOT EXISTS`, перевірка `information_schema` + `PREPARE`) — як у `legacy/`.
3. Внесіть ту саму зміну в `database/schema.sql` (нові інсталяції беруть схему звідти) і додайте рядок міграції до `INSERT IGNORE INTO schema_migrations … 'baseline'` наприкінці `schema.sql` — тоді свіжа база не виконуватиме її повторно.
4. Додайте перевірку наслідку в `SystemStatus::schemaChecks()` (необов'язково, для сторінки «Стан системи»).
5. Файл після застосування **не редагуйте** — контрольна сума записана в журналі; для змін створюйте нову міграцію.

Скрипт виконується через PDO по одному оператору: підтримуються коментарі `--`, `#`, `/* */`, рядки з `;`, `PREPARE/EXECUTE`; `DELIMITER` і збережені процедури/тригери — ні.
